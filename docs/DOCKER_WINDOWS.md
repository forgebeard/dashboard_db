# Установка Docker в Windows

Инструкция предназначена для подготовки рабочей станции Windows к запуску RED Virt Analytics через Docker Desktop.

Официальная документация: [Install Docker Desktop on Windows](https://docs.docker.com/desktop/setup/install/windows-install/).

## 1. Проверьте требования

Для работы Docker Desktop необходимы:

- поддерживаемая 64-разрядная версия Windows;
- аппаратная виртуализация, включённая в BIOS/UEFI;
- WSL 2;
- права на установку программного обеспечения в соответствии с политикой организации;
- не менее 4 ГБ оперативной памяти, рекомендуется больше для одновременной работы PostgreSQL и RED Virt Analytics.

Проверьте виртуализацию:

1. Откройте **Диспетчер задач**.
2. Перейдите в **Производительность → ЦП**.
3. Убедитесь, что поле **«Виртуализация»** имеет значение **«Включено»**.

Если виртуализация выключена, включите Intel VT-x или AMD-V в BIOS/UEFI. Название настройки зависит от производителя компьютера.

> Перед установкой проверьте условия лицензирования Docker Desktop, действующие в вашей организации. Для некоторых вариантов коммерческого и государственного использования может потребоваться платная подписка.

## 2. Установите или обновите WSL 2

Откройте PowerShell или Windows Terminal от имени администратора и выполните:

```powershell
wsl --install
```

После завершения перезагрузите компьютер, если Windows запросит перезагрузку.

Обновите WSL:

```powershell
wsl --update
```

Проверьте версию:

```powershell
wsl --version
```

Docker рекомендует WSL версии не ниже 2.1.5. Желательно использовать актуальную доступную версию.

Если команда `wsl --install` недоступна или завершается ошибкой, используйте официальную инструкцию Microsoft по установке WSL либо обратитесь к системному администратору.

## 3. Скачайте Docker Desktop

Скачайте установщик только с официальной страницы:

[Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/)

Выберите сборку для архитектуры компьютера:

- `x86_64` — большинство рабочих станций с процессорами Intel или AMD;
- `Arm` — устройства Windows on ARM.

## 4. Установите Docker Desktop

1. Запустите загруженный установщик.
2. Разрешите установку компонентов, если появится запрос Windows.
3. Выберите использование **WSL 2 based engine**, если установщик предлагает выбор backend.
4. Завершите установку.
5. Перезагрузите Windows, если установщик запросит это.

Не устанавливайте отдельный Docker Engine внутри дистрибутива WSL: одновременная установка Docker Desktop и второго Docker Engine может привести к конфликтам.

## 5. Запустите Docker Desktop

1. Откройте **Docker Desktop** через меню «Пуск».
2. Примите условия использования, если они соответствуют политике вашей организации.
3. Дождитесь завершения запуска Docker Engine.

В интерфейсе Docker Desktop должно отображаться состояние работающего движка без критических ошибок.

При использовании WSL 2 обычно дополнительная установка отдельного Linux-дистрибутива для RED Virt Analytics не требуется.

## 6. Проверьте установку

Откройте новое окно PowerShell или `cmd` и выполните:

```powershell
docker version
docker compose version
docker info
```

Docker Desktop уже включает Docker Engine, Docker CLI и Docker Compose. Дополнительно устанавливать Compose в Windows не требуется.

Дополнительная проверка:

```powershell
docker run --rm hello-world
```

При первом выполнении Docker загрузит тестовый образ из внешнего реестра.

## 7. Проверьте режим контейнеров

RED Virt Analytics использует Linux-контейнер.

Если Docker Desktop переключён в режим Windows containers, откройте меню Docker Desktop и выберите **Switch to Linux containers**. Если такого пункта нет, Linux-контейнеры уже используются.

Проверить тип системы можно командой:

```powershell
docker info --format '{{.OSType}}'
```

Ожидаемый результат:

```text
linux
```

## 8. Возможные проблемы

### Docker Desktop не запускается

Проверьте:

- включена ли аппаратная виртуализация;
- установлен ли WSL 2;
- выполнена ли перезагрузка после установки компонентов Windows;
- разрешён ли Docker Desktop политиками безопасности организации.

Команды проверки:

```powershell
wsl --status
wsl --version
wsl -l -v
```

### `docker` не является внутренней или внешней командой

Закройте терминал, запустите Docker Desktop и откройте новое окно PowerShell или `cmd`.

Если ошибка остаётся, проверьте завершение установки Docker Desktop и перезагрузите Windows.

### `Cannot connect to the Docker daemon`

Docker Desktop не запущен либо Docker Engine ещё загружается. Запустите Docker Desktop и дождитесь готовности движка.

### Ошибка WSL или `Unexpected WSL error`

Выполните:

```powershell
wsl --shutdown
wsl --update
```

После этого перезапустите Docker Desktop. Если ошибка сохраняется, проверьте компоненты **Windows Subsystem for Linux** и **Virtual Machine Platform** в окне «Включение или отключение компонентов Windows».

### Не загружаются образы

Проверьте доступ к внешним реестрам, DNS и корпоративный прокси-сервер. При наличии прокси настройте его в Docker Desktop в соответствии с политикой организации.

## 9. Следующий шаг

После успешного выполнения `docker compose version` вернитесь к [руководству администратора RED Virt Analytics](ADMIN_GUIDE.md) и продолжите установку приложения.
